Logarifm nima?

Logarifm - berilgan sonni olish uchun logarifm asosini qanday darajaga ko'tarish kerakligini ko'rsatadigan matematik amal.

logₐ(b) = c ⇔ aᶜ = b

Logarifm xossalari

  • Ko'paytmani logarifmi: logₐ(xy) = logₐ(x) + logₐ(y)
  • Bo'linmani logarifmi: logₐ(x/y) = logₐ(x) - logₐ(y)
  • Darajani logarifmi: logₐ(xᵖ) = p·logₐ(x)
  • Asosni almashtirish: logₐ(b) = logₓ(b) / logₓ(a)

Maxsus logarifmlar

Nomi Belgisi Asosi

Natural logarifm ln e ≈ 2.718
Ikkilik logarifm lb 2

Misol: log₂(8)

2 ning qanday darajasi 8 ga teng? 2³ = 8, demak log₂(8) = 3

Hosila nima?

Hosila - funksiyaning o'zgarish tezligini o'lchaydigan asosiy tushuncha. Funksiyaning ma'lum bir nuqtadagi hosilasi, o'sha nuqtadagi egri chiziqqa urinma chiziqning burchak koeffitsientiga teng.

f'(x) = limh→0 [f(x+h) - f(x)] / h

Asosiy hosila qoidalari

Funksiya Hosila
c (doimiy) 0
xⁿ n·xⁿ⁻¹
sin(x) cos(x)
cos(x) -sin(x)
eˣ eˣ
ln(x) 1/x

Hosila qoidalari

  • Yig'indining hosilasi: (f+g)' = f' + g'
  • Ayirmaning hosilasi: (f-g)' = f' - g'
  • Ko'paytmaning hosilasi: (f·g)' = f'·g + f·g'
  • Bo'linmaning hosilasi: (f/g)' = (f'·g - f·g') / g²
  • Murakkab funksiya hosilasi: (f(g(x)))' = f'(g(x))·g'(x)

Misol: f(x) = x³ hosilasi

f'(x) = 3x²

x=2 nuqtada: f'(2) = 3·2² = 12

Geometrik formulalar

Doira

  • Yuzi: S = πr²
  • Uzunligi: C = 2πr

To'rtburchak

  • Yuzi: S = a·b
  • Perimetri: P = 2(a+b)

Uchburchak

  • Yuzi: S = ½·a·h
  • Perimetri: P = a+b+c

Sfera

  • Hajmi: V = (4/3)πr³
  • Sirti: A = 4πr²

Silindr

  • Hajmi: V = πr²h
  • Sirti: A = 2πr(h+r)

Misol: Radiusi 5 bo'lgan doira

Yuzi: S = π·5² = 25π ≈ 78.54

Aylana uzunligi: C = 2π·5 = 10π ≈ 31.42

Trigonometriya asoslari

Trigonometriya - uchburchaklar va ularning tomonlari va burchaklari o'rtasidagi munosabatlarni o'rganadigan matematika sohasi.

cos(θ) = Yon tomon / Gipotenuzа
tan(θ) = Qarama-qarshi tomon / Yon tomon

Diskriminant nima?

Diskriminant kvadrat tenglamaning ildizlari soni va turini aniqlash uchun ishlatiladigan formuladir.

D = b² - 4ac

Diskriminant qiymatiga qarab:

  • D > 0 bo'lsa, tenglamaning ikkita haqiqiy ildizi bor
  • D = 0 bo'lsa, tenglamaning bitta haqiqiy ildizi bor (ikki marta takrorlanuvchi)
  • D < 0 bo'lsa, tenglamaning haqiqiy ildizlari yo'q (kompleks ildizlar)

Kvadrat tenglama formulasi

x = (-b ± √D) / (2a)
